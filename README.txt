# The Daily Grind Café Website

A responsive café landing page built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation and menu category filters

## Run
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and the remote Unsplash photos.

## Customise
Update the café name, menu items/prices, address, phone, email, and opening hours in `index.html`. Replace the sample photo URLs with your own images if desired. The address and contact details are sample content.
